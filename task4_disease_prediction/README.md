# CodeAlpha Task 4 — Disease Prediction from Medical Data

## Objective
Predict the possibility of disease from structured medical measurements using classification techniques.

## Dataset
The project uses scikit-learn's built-in breast-cancer classification dataset, which is suitable for the educational task and keeps the repository lightweight.

## Models
- Logistic Regression with feature scaling
- Random Forest with class balancing

## Evaluation
Accuracy, Precision, Recall, F1-Score and ROC-AUC.

## Important
This is an educational machine-learning project. Predictions are not medical diagnoses and must not be used for clinical decision-making.

## Run
```bash
pip install -r ../requirements.txt
python train_model.py
python predict.py
```
